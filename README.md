# BizCare-Connect-Solution
BizCare Connect is a fully coded website offering professional, on-demand task support for homes and small businesses. Built using HTML, CSS, Bootstrap, jQuery, and Font Awesome icons, the site includes a custom login page, interactive pricing layout, and mobile-first responsive design.
BizCare Connect | Full Website Project
Project Overview:
BizCare Connect is a fully responsive, multi-page website designed for a task support company serving homes and small businesses across DC, Maryland, and Virginia. This site was built from scratch using HTML5, CSS3, Bootstrap 5, and jQuery, with Font Awesome integration for modern UI icons. The project highlights a mobile-first design approach with a user-friendly interface and visual branding that aligns with BizCare’s core values: trust, support, and community care.
Key Features:
Custom Login & Sign-Up Page with working Formspree forms and branded buttons


Pricing Page with styled cards, icons, and visual flair


Services Page organized by service area and categories (core and custom requests)


About, Contact, Blog, and How It Works Pages for clear navigation and communication


Hero Sections with gentle gradients, layered icons, and subtle animations


Custom Background Watermarks and butterfly imagery for brand identity


Footer with Social Media Links using Font Awesome


Mobile-First & Fully Responsive Layout


Smooth hover effects, custom buttons, and animation


Tech Used:

CSS3 (internal + external styling)
